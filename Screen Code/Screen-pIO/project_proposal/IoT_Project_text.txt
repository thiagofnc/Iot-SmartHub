Objectives  and  Specifications
 ●  Use  three  ESP32  devices  each  for  screen,  main  controller,  and  camera.   ●  Enable  wireless  communication  using  both  BLE  and  one  LoRA  technologies  for  short

 ●  Provide  User  Friendly  UI  for  monitoring  and  control.  ●  The  screen  should  turn  off  when  the  user  is  not  present.  ●  Must  report  data  such  as  temperature,  humidity,  and  light  level  from  sensors.  ●  Main  ESP32  LoRa  node  powered  by  a  simple  battery.  (I  think  we  need  a  5V  battery,
