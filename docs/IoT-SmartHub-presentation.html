IoT Project Presentation

IoT-SmartHub

A connected ESP32-based smart hub that combines camera capture, wireless communication, BLE device interaction, Wi-Fi web services, servo control, and an interactive display UI.

Project Goal

One Hub, Multiple Interfaces

Camera

Vision Input

Captures JPEG frames, streams video, and records gesture datasets to SD card.

Connectivity

BLE, Wi-Fi, LoRa

Uses short-range BLE, local Wi-Fi services, and a LoRa path for long-range low-data messages.

Output

Display + Servo

Shows live status on the dashboard and can physically actuate a servo motor.

System Architecture

Camera Module

Camera Capture and Dataset Recording

  • Target board: Seeed Studio XIAO ESP32S3 Sense.
  • Camera firmware exposes /capture for a still JPEG and /stream for MJPEG preview.
  • Dataset capture records labeled gesture clips such as up, down, left swipe, right swipe, rotate, and idle.
  • Frames are saved to the microSD card and can be downloaded as dataset.zip.
Wi-Fi Connection

Local Web Services and API Access

  • ESP32 connects as a Wi-Fi station and prints its IP address over serial.
  • SmartHub firmware includes an HTTP server with a sample battery endpoint: /battery?phone=85.
  • Screen firmware uses Wi-Fi for OpenWeather data, NTP time sync, and Spotify Web API controls.
  • Wi-Fi status is shown on the display as connected, connecting, or offline.
BLE Connection

Bluetooth Low Energy Device Link

  • The hub advertises a BLE UART-style service for receiving and sending messages.
  • It scans nearby BLE devices and looks for a target watch device.
  • After connection, it can read GATT device information such as device name and model number.
  • The OLED status screen shows whether the watch is scanning or connected.
LoRa Connection

Long-Range Low-Power Messaging

  • LoRa is useful when Wi-Fi is unavailable or the sensor node is far from the hub.
  • Example payloads: motion event, battery level, door state, temperature, or emergency alert.
  • The hub can receive LoRa packets and forward the status to the display or Wi-Fi dashboard.
  • Typical ESP32 libraries include RadioLib or LoRa by Sandeep Mistry, depending on the LoRa module.

Servo Motor

Physical Control Output

  • A servo motor can represent a smart lock, camera pan/tilt, vent flap, pointer, or small robotic action.
  • The ESP32 drives the servo using PWM, usually with a 50 Hz signal.
  • Example actions: open at 90 degrees, close at 0 degrees, or move based on BLE/Wi-Fi/LoRa command.
  • For reliable motion, power the servo from a suitable external 5 V supply and share ground with the ESP32.

How to Present the Project

  • Power on the SmartHub and show the display booting into the clock/dashboard UI.
  • Connect Wi-Fi and open the camera page from the serial monitor IP address.
  • Show /stream for live preview and /capture for a still image.
  • Connect or scan for the BLE watch and show the device name/model on the OLED.
  • Trigger a servo action from a command, such as unlock, rotate, open, or close.
  • Describe LoRa as the long-range sensor link for remote events.
Example Slide Speech

Short Explanation

"Our IoT-SmartHub is an ESP32-based hub that brings together several common IoT interfaces. The camera module captures image data and can stream or record gesture datasets. Wi-Fi provides local web endpoints and cloud API access. BLE connects to nearby devices such as a smart watch. LoRa can be added for long-range low-power sensor messages, and a servo motor gives the system a physical output. The display UI brings everything together so the user can quickly see the hub status."

Conclusion

What the SmartHub Shows

  • Multiple IoT communication methods in one project.
  • Real sensor input through camera capture and BLE scanning.
  • Useful network services through Wi-Fi endpoints and APIs.
  • Human-friendly feedback through the display UI.
  • Physical interaction through servo motor control.
